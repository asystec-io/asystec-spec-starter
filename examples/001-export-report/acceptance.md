# Aceptación

AC-001 y AC-002 aparecen completos en spec.json. El ejemplo define entradas conocidas y resultados observables, incluyendo casos negativos.

Las referencias asumen que se copia examples/code a example-code dentro del proyecto de demostración. El test de integración del starter realiza esa copia y valida el contrato de manera estricta. Las pruebas de comportamiento se ejecutan aparte mediante unittest.

Esta demostración no constituye aprobación de un producto real ni garantiza comportamiento fuera de su alcance.
