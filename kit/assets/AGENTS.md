# Guía de agentes: desarrollo guiado por especificaciones

Integrar estas instrucciones con el AGENTS.md existente, después de revisión humana.

1. Leer .specify/GUIDE.md, .specify/project.json y la feature en specs/ antes de editar código.
2. No implementar requisitos ambiguos: documentar preguntas, alcance y riesgos.
3. Actualizar spec.json, spec.md y plan.md antes de cambiar el comportamiento esperado. Registrar cambios en change.md.
4. Mantener R-xxx → AC-xxx → T-xxx → referencia de prueba; no inventar evidencia.
5. Ejecutar pruebas reales del proyecto y validación estructural; informar cada una por separado.
6. No tratar una validación verde como aprobación de producto, seguridad o calidad semántica.
7. No instalar herramientas, publicar, hacer merge ni desplegar sin la autorización correspondiente.
8. No introducir secretos, datos de clientes o código privado en ejemplos públicos.
9. No sobrescribir archivos existentes del proyecto para adoptar este starter.
